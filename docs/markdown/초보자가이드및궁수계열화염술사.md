# 마비노기 모바일 통합 가이드

# 초보자 육성 가이드

## 가이드 구성

- 전체 육성법 및 핵심 꿀팁
- 1레벨 ~ 65레벨 구간
- 65레벨 ~ 85레벨 구간 (장비 세팅 포함)
- 85레벨 이후 구간

---

## 육성법

게임의 시작부터 끝까지 아래 순서를 따른다.

1. **메인 퀘스트**를 민다
2. **판타지 라이프**를 민다
3. **사이드 퀘스트**를 민다

### 메인 퀘스트
- 메인 퀘스트만 따라가면 레벨 상승, 장비 보상, 콘텐츠 해금이 자동으로 이루어지므로 최우선 진행 권장

### 판타지 라이프
- 주요 보상: 각종 성장 재료 + 65레벨 시 공물 상자
- 초반 보상은 적지만 후반으로 갈수록 유용한 보상 증가
- 단계별 퀘스트 구조이므로 초반부터 꾸준히 진행 권장

### 사이드 퀘스트
- 주요 보상: **은동전** (던전·사냥터 입장 재화)
- 은동전 10개 이상을 보상으로 주는 퀘스트는 반드시 던전에서 진행되며, 메인 퀘스트와 겹치는 경우 동시에 클리어 가능
- 퀘스트 창에서 보상을 미리 확인하여 은동전 10개 이상인 퀘스트를 우선 수락
- 연계 퀘스트 형식도 있어 전부 확인은 불가
- 메인 퀘스트가 막혔을 때(레벨 조건·지역 달성도·은동전 부족) 병행 진행하는 방식도 유효

---

## 핵심 꿀팁

- **자동 진행 중 고양이 상인·캠프파이어 납치 방지**: [환경 설정] → [게임] → 자동 진행 항목에서 해제
- **사냥터 무료 입장**: 사냥터 입장 UI에서 왼쪽 가장 큰 네모 칸의 선택을 해제하면 은동전 소모 없이 입장 가능
- **던전 은동전 환급**: 입장 후 퇴장 시 은동전을 돌려받음. 퇴장 버튼은 우측 상단 맵에 위치. 바로 나오면 10개 전액 환급, 문을 하나라도 열면 9개 이하로 환급
- **S랭크 클리어**: 모든 던전은 S랭크로 클리어해야 최초 클리어 보상과 업적을 획득 가능. 살아있는 상태로 클리어하거나 1회 사망 후 부활한 경우까지 S랭크 인정

## 1레벨 ~ 65레벨 구간

- 스토리 스킵 시 불이익 없음
- 길에서 서브 퀘스트로 납치될 경우 일단 수락만 해두기 (나중에 재방문 번거로움 방지)
- 메인 퀘스트에서 일정 레벨 달성 요구 시 '추천 레벨업 장소' 이용
- **주간 목표 퀘스트**, **고로 퀘스트**는 만렙 이전에는 무시

### 레벨업 보너스 카드 우선순위
1. 주스탯 성장 카드
2. 공격 우선 카드
3. 치명타 관련 카드 (행운 성장, 기교 우선)

### 장비
- **자동 장착**만 사용
- 나머지는 '간단한 정리하기'로 분해 (왼쪽 두 개 항목만 체크)

### 음식
- **여행자 간식** 또는 **삶은 달걀** 제작 권장
- 제작 경로: 크래프팅 → 제작 → 음식
- 계란 채집 추천 장소: 던바튼 둥지에서 12시 방향 알둥지 (수탉 출현 빈도 낮음)
- 재료 획득처 확인: 해당 아이템 클릭 → [구하는 방법]

### 물약
- 체력 회복이 부족하다고 느껴질 때 치료소 NPC → [매일 특가] 탭에서 높은 단계 물약 구매 후 퀵슬롯 등록

### 가방
- 인벤토리 부족 시 여관 NPC → [특별 판매] 탭에서 하트 토큰으로 가방 구매

### 마족 공물
- 55레벨 해금, 심층 던전 입장 재화
- 12시간마다 1개씩 충전, 최대 10개 보유
- 10개가 차면 1개씩 소비하여 낭비 방지
- 공물 1개 사용 시: 심층 던전 S랭크 해금 용도로 활용

### 정령의 흔적
- 모아두기 권장. 게임 중 팝업이 뜨더라도 무시
- 추후 업적 달성(다재다능, 만능천재)에 사용하는 것이 효율적

### 퀘스트 팁
- **고로 퀘스트** (55레벨 이후 해금): 최대 효율을 원하면 엠블럼 룬 [현란함]으로 진행 권장
- **던바튼 NPC 아이라 가이드북 퀘스트**: 가이드북을 모두 구매한 후 퀘스트를 전부 받은 상태에서 한 번에 클리어 권장 (가이드북 1개당 은동전 1개 보상)

## 65레벨 ~ 85레벨 구간

### 진행 순서
1. 65레벨 이후 메인 퀘스트가 순차적으로 해금됨
2. **글라스기브넨 [입문]** 클리어 ('우연한 만남' 활용 권장, 일반적으로 오버스펙으로 패턴 숙지 없이 클리어 가능)
3. 위 퀘스트 클리어 후 심층 던전 퀘스트 시작
4. 심층 던전 진입 전 **장비 세팅** 시작 권장
5. 장비 세팅 타이밍: **이멘 마하 메인 스토리 완료 후** 권장 (퀘스트 보상으로 고성능 장비 제공)

---

## 장비 세팅 ① 장비

> 핵심 요약: **좋은 베이스 아이템에 좋은 룬 각인하기**

### 재질 선택
- 힘 계열 → **중갑**
- 솜씨 계열 → **경갑**
- 지력 계열 → **천옷**

### 좋은 베이스 아이템 선정 및 잠금
1. 인벤토리에서 '착용 레벨 순'으로 정렬
2. 각 부위에서 레벨이 가장 높은 아이템들을 일일이 클릭하여 [기본 능력치] 확인
   - '착용 레벨 순' 정렬은 기본 능력치 순 정렬이 아니므로 직접 확인 필요
3. 기본 능력치가 높고 자신의 재질에 맞는 아이템 잠금
4. 모든 부위에서 1개씩, **반지만 2개** 잠금
- **베이스 아이템의 성급은 0~3성 권장**: 룬 각인 시 기존 룬은 분해되어 사라지므로 높은 룬이 박힌 고성급 베이스는 분해 후 룬 추출 → 룬 승급 재료로 활용

### 나머지 장비 분해 및 룬 추출
- '간단한 정리하기'로 분해
- 전부 분해 시: 가방 → [정리] → [자세히 정리하기] → 왼쪽 체크 모두 해제 → 분해

### 룬 5성 승급
- 경로: 크래프팅 → 연금술 → 룬 승급
- [재료 자동 넣기] + [모두 승급]으로 5성까지 승급
- **연금술 재연소 촉매**는 일단 아껴두기

### 베이스 아이템에 룬 각인
- 대장장이 NPC에게 [룬 각인]
- 룬은 **숫자가 높은 것** 우선 (색깔은 초반에는 무시)

### 저주 해제
- 총 3가지 방법 존재. 1번 방법이 가장 쉬우며 초반에는 3번 방법도 유용

### 장비 업그레이드 방법
- 더 좋은 베이스 아이템 획득 시 → [성능 개선]
- 더 좋은 룬 획득 시 → [룬 각인]

#### 성능 개선 조건
- 같은 부위끼리만 가능
- 기본 능력치가 같거나 더 높은 장비에만 적용 가능
- **무기**: 동일한 무기에만 가능
- **방어구**: 재질 무관하게 가능

---

## 장비 세팅 ② 보석

> 핵심 요약: 아이템 소켓에 **투박한 스타프리즘** 만들어서 착용

### 진행 순서
1. 모든 보석을 **투박한 OOO**까지 승급
   - 크래프팅 → 연금술 → 보석 승급 → [재료 자동 넣기] + [모두 승급]
2. **투박한 트리플쿼츠** 합성
   - 투박한 색보석 3종 합성
3. **투박한 다크라이트** 합성
   - 투박한 다이아몬드 + 투박한 흑요석 합성
4. **투박한 스타프리즘** 합성
   - 투박한 트리플쿼츠 + 투박한 다크라이트 합성
5. 이후 업그레이드: 투박한 스타프리즘 3개 합성 → **투박한 스타프리즘S**로 단계별 업그레이드

---

## 장비 세팅 ③ 기타

### 소켓
- 무기·방어구: 최대 3소켓 / 악세·엠블럼: 1소켓
- 소켓 늘리는 방법: [성능 개선] 시 두 아이템 중 많은 소켓 수를 따라감
  - 3소켓이 될 때까지 기다리거나, 3소켓 장비끼리 성능 개선

### 각인 강화
- **6성 룬부터** 각인 강화 시작 권장 (6성 이상 룬으로 덮어씌울 때 강화 수치가 그대로 이전됨)
- 강화 순서: **무기 → 악세 → 엠블럼 → 방어구**
- **강화 재연소 촉매**: 무기를 12강 완성 후 **13강 도전부터** 전부 무기에 집중 사용. 다른 부위에 사용 비권장

---

## 심층 던전

### 마족 공물
- 주요 수급처: 12시간마다 1개 자동 충전 / 데카·캐시 구매 / 퀘스트·이벤트 보상
- **85렙 아이템은 '남쪽 폐허 심층'부터 드롭됨** → 스펙업의 핵심 콘텐츠

### 효율적인 공물 사용 순서
1. 65레벨 이후 콘텐츠 해금용 메인 퀘스트 3개 클리어 → 심층 던전 퀘스트 순차 해금
2. 심층 던전 퀘스트 1번·2번·3번만 클리어
3. **남쪽 폐허 심층**부터 전 구역 클리어하며 85렙 아이템 파밍
4. 바리 1광구 심층 진입 가능한 전투력이 될 때까지 **남쪽 폐허 심층 2-3** 반복

### 공략 팁
- 혼자 돌기 어려우므로 **우연한 만남** 또는 **동행** 시스템 적극 활용
  - 우연한 만남: 문 하나 열고 잠시 대기하면 유저 매칭
  - 매칭 불가 시: 퇴장 후 입장 화면에서 [동행] 버튼 체크
- 심층 던전은 입장 후 언제 퇴장해도 **공물 1개 전액 환급**
- S랭크 클리어 필수 (최초 클리어 보상 및 업적)

---

## 85레벨 이후 구간

### 공물 사용처
- 최종 목표: **심층 던전 [매우 어려움]**
  - 공물 2개 소모 / 보상은 일반 심층의 2배 이상

### 은동전 사용처
- **던전**: 페론 고분 [어려움] 2-3
- **사냥터**: 각 마을의 사냥터 [매우 어려움] + 센마이 평원 [어려움]
- 골드가 급하게 필요한 상황이 아니라면 은동전은 던전 위주로 사용 권장

### 사냥터 [매우 어려움] 순서대로 도는 이유
- 보상 수준은 센마이 평원 [어려움]과 동일
- 초반 마을 사냥터일수록 낮은 단계의 **제작 재료** 및 **제작대 업그레이드 재료**가 드롭됨
- 낮은 단계 재료 확보를 위해 초반 마을 사냥터부터 순서대로 진행 필요

### 주간 목표 퀘스트
- **[주간 목표] 모험가 길드의 정기 의뢰**: 주마다 1회 클리어
  - 엘리트 연금술 재연소 촉매 주 1회 지급 / 클리어마다 골드 3만 추가 지급

### 지역 정화 퀘스트 / 지역 업적
- 각 마을의 던전·사냥터 모든 단계 해금에 공물·은동전 소모 필요
- 재화 대비 보상이 크지 않아 **초반 스펙업 구간에서는 비권장**

# 부캐 활용 가이드

## 부캐의 필요성

- 부캐는 필수는 아니지만 함께 키우면 **본캐 성장 속도가 빨라짐**
- 부캐에게 본캐와 똑같은 자본을 투자할 필요는 없음
- **공용 보관함으로 이동 가능한 아이템·재화를 부캐에게 집중 투자**하는 방식으로 활용

---

## 클래스 레벨업

- 패치 이후 **본 무기(60 클래스)를 착용한 상태로 던전을 돌아도 정령의 흔적 획득 가능**
- 약한 무기를 들고 던전에 갈 필요 없이 혼자서도 수월하게 클래스 레벨업 가능

---

## 올라운더 칭호

- 공격력·방어력 **275씩 증가**
- **장착하지 않아도 적용**되는 효과 → 달성만 하면 기본 스탯으로 반영됨
- 계정 내 캐릭터 중 **가장 높은 클래스 레벨을 기준으로 확산**
- 부캐로 은동전·마족 공물을 소모하면 훨씬 빠르게 클래스 레벨을 올릴 수 있음

---

## 매일 부캐 루틴

- 토탈 멤버십 사용 시 **은동전 최대치 +50개, 마족 공물 +5개** 추가 보유 가능
- 한꺼번에 모아두지 말고 **매일 조금씩 소모**하는 것이 효율적

---

## 부캐로 재화 수급하기

### 패션 티켓 조각 / 보물 상자
- 부캐로 마족 공물을 사용해 심층 던전을 돌면 **패션 티켓 조각 보물 상자** 획득 가능
- 공용 보관함으로 이동 가능 → 본캐에게 전달

### 룬 파편
- 던전을 돌면 **룬 파편** 획득 가능
- 공용 보관함으로 이동 가능 → 본캐에게 추가 수급

### 안정된 미스틱 열쇠 / 초월 각인 완성품
- 매주 어비스·레이드에서 획득 가능
- 공용 보관함으로 이동 가능
- 열쇠는 많이 보유할수록 신화 룬을 만날 확률 증가
- 초월 각인 재료는 직접 제작하여 거래소에 판매(데카 수급)하고, 레이드·심층에서 드롭되는 **완성품으로만 초월 강화**를 진행하는 방식도 유효

---

## 추가 팁

- 멤버십 사용 시 부캐로 **멤버십 아르바이트**를 돌려 골드 추가 수급
- 생활 콘텐츠 재료를 부캐로 구매하여 제작에 활용
- **캐릭터별 보상을 지급하는 이벤트** 진행 시 부캐가 2~3개 있으면 보상량이 크게 늘어남

# 화염술사 공략 가이드

## 기본 특성

- **자원**: 열기 (빨간색 게이지)
- 열기를 수급하고 소모하면서 공격하는 클래스
- **소모 스킬**이 주력기
- 상대하는 몹이 많을수록 강력해지는 클래스
- **궁극기 대미지 지분이 높아** 궁극기 활용이 핵심

---

## 패시브

### 버닝 소울
- 화염술사 패시브의 핵심
- 열기 소모량에 따라 **1단계 ~ 3단계** 버프 존재
- 단계가 높을수록 최종 대미지 증가량이 늘어남
- **3단계 상태를 빠르게 유지**하는 것이 목표 (유지 시간 25초, 이 구간이 가장 강한 딜 타임)
- 마스터 엠블럼 착용 시: 버닝 소울 3단계에서 열기 소모 스킬 사용 시 공격력 증가 버프 획득 (최대 5중첩, 소모 스킬 사용마다 1스택씩 누적)

### 오버히트
- 버닝 소울 단계에 따라 **쿨타임 감소** 효과 제공
- 버닝 단계가 변경될 때마다 남은 쿨타임 퍼센트에 따라 쿨타임이 변동됨
- 단계가 올라가면 쿨타임 감소, 단계가 꺼지면 쿨타임 증가
- 높은 단계 유지에 집중하면 자동으로 관리됨

---

## 궁극기

- **1단계**: 광선 대미지 (약함)
- **2단계**: 메인 딜 구간 (짧지만 가장 중요) → 2단계를 전부 맞추는 것이 핵심
- 부가 효과:
  - 궁극기 사용 시 버닝 소울 **3단계로 즉시 진입**
  - 시전 중 열기 생성
  - 종료 후 사용 시간에 비례한 **열기 회복 버프** 부여

### 궁극기 팁
- **후 딜레이 캔슬**: 궁극기가 끝나기 직전에 살짝 움직이면 후 딜레이 없이 바로 다음 스킬 사용 가능 (대미지는 전부 적용됨)
- **사용 타이밍**: 쿨타임이 돌아왔다고 바로 사용하지 말고, 약 1분 30초 기다렸다가 각성 켜졌을 때 사용
- 또는 각성 직전에 사용하여 **1단계는 각성 전, 2단계는 각성 중**에 맞추는 방법도 유효

---

## 장신구 트리 (세팅)

### 공통 스킬 개조
- **잿더미·불기둥 트리**: 1번·5번·6번 개조
- **청염·발화 트리**: 3번·5번·6번 개조

---

## 트리 1: 잿더미 + 불기둥 + 분출

**특징**
- 안정적인 저점
- 단일 몹 대상으로 강력
- 브레이크가 필요한 던전에 적합

### 분출 룬
- 화염술사 딜 구조의 핵심 룬
- 각인 시 지속 시간 기본 2초 추가
- 열기 소모 시마다 지속 시간 연장 → **최대 30초** 유지 가능
- 사용 즉시 화염 파동 발사 → 작열 재부여 가능
- **열기 수급의 핵심 수단**

### 불기둥 룬
- 보조 열기 수급 수단
- 기본 쿨타임 20초 → **2스택 + 쿨타임 감소**로 변경
- 폭발 지연 시간 5초 → **1초**로 감소
- 폭발을 자주 발생시켜 1스킬 초기화 유도 → 열기 수급 증가
- **핵심 콤보**: `5 → 2 → 1 → 1`
  - 불기둥(2번) 폭발 1초 대기 중 1스킬 두 번 사용 가능

### 잿더미 룬
- 불길과 작열을 원하는 대상에게 집중적으로 발사 가능

### 사이클
1. 3번 스킬로 시작
2. 5번 스킬 전 4번으로 주변에 작열 부여
3. `5 → 2 → 1 → 1` 콤보 반복 → 버닝 3단계 진입
4. 3단계 이후: `5 → 1 → 3 → 1` 과 `5 → 2 → 1 → 1` 번갈아 사용

> **버스트 캐논 (3번 스킬)**: 버닝 소울 3단계에서만 사용 가능. 캐스팅 시간 2초 → 1.5초로 단축, 폭발 판정 추가

---

## 트리 2: 청염 + 발화 + 분출 (시즌 1 신규)

**특징**
- 사이클이 단순해 운용이 쉬움
- 추가타가 잘 터질 경우 높은 고점 기대 가능
- 단일몹 + 다수 처리를 동시에 해야 하는 상황에 적합

### 청염 룬
- 버닝 소울 효과 추가 → 대미지 증가
- 3번 스킬이 **소모 스킬로 변경** (열기 50 이상 시 사용 가능)
- 버닝 소울 단계가 있을 때 열기 일정량 환급
- 캐스팅 유지, 쿨타임 단축
- **청염이 주력 대미지** (궁극기와 대미지 지분이 비슷한 수준)

### 발화 룬
- 청염의 열기 환급만으로 부족한 열기를 보충하는 수단
- 폭발 판정 2회 발생 (발사 시 1회 + 착탄 시 1회)

### 사이클
1. `2 → 4 → 5` 사용 → 열기 생성 버프 획득
2. 1번 스킬 2회 사용
3. 3번 스킬 사용
4. **평타 1회** 후 5번 스킬 사용 → 버닝 3단계 진입
5. 이후 `3 → 1 → 5 → 1` 반복

## 장비 세팅

### 레이드 세팅
- **무기**: 검무 (대체제: 불길 룬 또는 공격 관련 룬)
- **방어구**: 교복 세팅 (압도·섬세)
- **공증 룬**: 창백한 섬광 (일렁이는 물꽃보다 미세하게 대미지 높음)
  - 창백한 섬광 사용 시 들불 룬은 비권장
- **피증 룬**: 황혼 (브레이크 불가 던전은 단조된 빛도 사용 가능)
- 보석 세공이 완성되지 않은 경우 직접 피해 룬 1개가 오히려 효율적일 수 있음

### 기갱 세팅 (브레이크·각성 집중)

**브레이크 즉시 격파 (1브 세팅)**
- 무기: 파괴자
- 방어구 룬: 압도·섬세·땅울림·분쇄·악의 (갈퀴 대체 가능, 악의가 더 효율적)

**브레이크 2회 세팅**
- 땅울림 → 레이드 룬으로 교체
- 비약: 치명 비약
- 공증 룬: 일렁이는 불꽃

### 영원 세팅
- **룬워드 우선순위**
  - 1티어: 계속 이어지는 이야기 포함 4종
  - 2티어·3티어: 순위에 따라 채용
  - 브레이크 집중 시: 피할 수 없는 징표 1순위
- **무기 인챈트**: 조화 권장
- **아티팩트 우선순위**: 강인함(치명타 확률) → 기교(추가타) → 연타·강타 → 원소(속성 피해) → 조화(주는 피해) → 순수(공증) → 분쇄(브레이크 시 필수)

## 어비스 공략 (궁극기 빌드 기준)

> 어비스 메타에서는 치비 대신 **궁비(궁극기 비약)** 사용 권장

### 대공동

**1번 방 (놀 브레이크)**
- 장신구: 불씨·분출·발화 고정
- 마지막 타이밍에 놀에게 궁극기 사용

**2번 방**
- 1번 방에서 궁극기를 소모했으므로 궁극기 충전에 집중
- 숙련 연계 변경(직업 변경) 강력 추천
  - 원소 태그가 겹치는 직업 권장: 전격술사·빙결술사·화염술사
- 궁극기가 없는 화염술사는 딜 기여가 낮으므로 직변 후 딜 권장

**3번 방**
- 일반 딜 플레이

### 신전
- 장신구: 섬세·갈퀴·악의·분쇄
- 스킬: 발화·분출·불씨 (분출 자리에 청염 대체 가능)
- 무기: 파괴자
- 진행 흐름: 브레이크 유도 → 바람탄 사용 → 궁비 획득 후 궁극기

### 부활의 신단
- 버스 탑승 또는 숙련 연계 변경 권장
- 앞방에서 비약 소모가 많으므로 **보스 방에서 창백한 섬광 장착** 권장

### 폐기장

**1번 방 (달리기 메타)**
- 분출 자리에 **불씨** 교체 → 궁극기 충전 문제 해결
- 무도가 필수 장착
- 각성을 조금 기다렸다가 진입

**2번 방**
- 첫 박치기 타이밍에 궁극기가 차 있어야 함
- 달리기 중 궁극기 게이지 관리 필수
- 무도가 장착 권장

# 궁수 계열 공략 가이드

---

## 궁수

### 기본 특성
- 메인 핵심 딜링기: **1번 애로우 리볼버**
- 기본 공격 및 스킬 적중 시 재사용 대기시간 감소 옵션이 **추가타에도 발동**
- 추가타를 최대한 확보해야 1번 스킬이 지속적으로 순환됨
- 가장 핵심적인 딜링기: **다발사격**
- **바람 스택** 존재

### 장신구 세팅
- **닻 룬 + 매의 룬**: 고정 룬
- 날렵한 빌드: 3번 스킬 사용 후 5초 이내에 다발사격 사용 시 최종 대미지 5% 증가

### 스탯 분배
- 치명타·추가타 반반 분배 권장
- 레벨업 보너스 카드: **행운 선택지가 나오는 모든 곳에서 행운 선택**
- 최종 목표치: 솜씨 280 / 행운 650 / 나머지는 공격력·치명타·추가타

### 룬워드
- 계속 이어지는 이야기 / 가벼운 마음 / 유리대포 / 얼음과 불

### 펫
- 1순위: 시추 (치명·연타)
- 대체: 라쿤 / 치마곰

### 아티팩트
- 치명타 / 추가타 / 공격력 / 무방비 / 연타 순으로 채용 후 종결

### 보석 세공
- 3줄: **연타·강타·방해**
- 2줄: 연타·강타 권장

### 인챈트 / 증폭
- 추가타·치명타 1순위
- 나머지 연타·강타

### 무기 룬
- 추가타 6,000 이상 확보 시: **검무**
- 추가타 4,500~5,000대: **망각**

### 장신구
- 날렵한 매·닻 또는 치명적인 매·닻

### 방어구 룬
- 면갑 → **모래폭풍**으로 대체
- 아득한 빛 / 압도 / 섬세 / 일렁 고정 + 1자리 스왑 (눈먼 / 약탈자 / 산들바람 채용)

### 신화 룬
- 어비스 기록 갱신을 하지 않을 경우: **무한** 권장
- 방어구 신화 룬: **전설 세트** 권장
- 쏟아지는 별 수령 후 룬워드 조합 추천

### 딜 사이클

**일반 사이클**
1. `5 → 4 → 1 → 3 → 1` → 다발사격
2. `5 → 1 → 3 → 1` → 다발사격
3. 1번 스킬 이후 **2번 스킬** 사용
- 핵심: **다발사격 시전 타이밍에 5번으로 전환**하여 사이클 유지

**궁극기 사이클**
- 궁극기 사용 중 `1 → 1 → 다발사격` 반복
- 궁극기 종료 후 일반 딜 사이클(`5 → 4 → 1 → 3 → 1`)로 복귀

**오토 세팅**
- 무기: 망각
- 장신구: 치명적인 계열
- 게임 설정에서 2번·3번 스킬 비활성화 후 오토 실행
- 평타 → 다발사격 자동 발동 → 1번 스킬 초기화 / 바람결 발동 시 치명적인 사격 → 다발사격 순으로 자동 순환
- 궁극기 게이지가 차면 수동으로 궁극기 사용

## 장궁병

### 기본 특성
- 전 직업 중 **최장거리** 사거리 보유
- 보조 스탯이 **의지**라 생명력이 높음
- 순수 방어 수단은 거의 없으나, 궁극기가 장전된 상태에서 **3번 스킬을 무적기로 활용** 가능
- **어시스트 모드에서 궁극기 자동 사용 불가** → 수동 운용 필요
  - 0시즌 친절함 엠블럼 룬(어시스트 모드 시 궁극기 자동 사용)이 존재한 바 있으나 현재는 별도 운용 필요
- 사거리로 원형 패턴 등 범위 공격 회피 가능

### 주력 스킬
- **3번·4번·궁극기**
- 스킬 개조: **3·4·6번**
- 태그: 강타·방해 계열

### 장신구 룬
- **고정**: 초음파 / 돌개
- **스왑**: 끈질김 / 내상 / 파쇄

### 딜 사이클

**8 사이클**
1. 유틸기 → 3번 → 다음 스킬 → 3번 → 궁극기 게이지 충전 → 6번
- 반깎·게이지 모음 필요 시: `1 → 4`로 시작
- 빠른 브레이크 필요 시: `2 → 4` 또는 `4 → 2`로 시작

**7 사이클**
- 8 사이클 대비 스킬 1회 감소한 사이클로 운용

### 핵심 스탯 우선순위
치명타 → 강타 → 추가타 → 연타

### 빠른 스킬 (빠스)
- 브레이크 후 딜 압축을 위해 중요하게 관리
- 권장 수치: **1,550 ~ 2,000**
- 레벨업 카드: 솜씨·공격 우선 → 브레이크·치명타(기교) 후순위

### 인챈트
- 무기: **활기**
- 방어구: 덩굴 / 올빼미 (빠른 스킬·치명타 제공)

### 엠블럼

### 장신구
- **폭스 헌터** 권장

### 아티팩트
- 순수 (공격력·강타·연타) / 치명타 확률(강인함)
- **지혜** (스킬 속도·캐스팅 속도 → 사이클 쾌적성 및 딜 압축 기여)
- 기교 / 분쇄 / 은의 기사도 선택지

### 변신 활용
- 유성우·연사·분노·가호 세트 활용
- 사이클 사이에 변신·해제를 통해 주력 스킬 딜링 보조

### 룬워드
- 필수: 계속 이어지는 이야기 / 나를 비추는 거울 / 가벼운 마음 / 얼음과 불
- 선택: 유리대포 / 피의 굶주림 / 쏟아지는 별
- 위 룬워드 미보유 시: 가벼운 마음·나를 비추는 거울의 하위 호환 룬워드 채용

### 펫

- 고점 세팅: 치명타·강타 고양이 + 장신구로 추가타 또는 극강타 보완

### 펫 스킬

### 무기 룬

## 석궁사수

### 기본 메커니즘
- 자원: **강화 볼트 스택**
- **스택 충전 스킬**: 1번·2번·3번
- **스택 소모 스킬**: 4번·5번 (쿨타임 없음, 스택 소모 시마다 사용 가능)
- 강화 볼트 소모 스킬 사용 시 **장전 스킬 공격 횟수 2배** 적용
- 스택 적립 없이 즉시 딜 가능 → 어비스에서 본인 전투력의 100%를 순간적으로 발휘하기 유리
- 레이드처럼 전투가 긴 콘텐츠에서는 지속딜이 부족함

### 핵심 패시브
- **드라이빙 포스**: 강화 볼트 소모 스킬 연속 사용 시 대미지 30%씩 증가 → 다른 스킬을 섞지 않고 연속으로 사용하는 것이 유리

### 장신구 세팅 (연반균 빌드 / 샷건 빌드)
- **반전 룬**: 스택 2개씩 동시 장전
- **균열 룬 (거스팅 볼트)**: 번개 범위 딜로 단일 특화의 약점 보완
- **연쇄 룬 (할로우 샷)**: 기관총형 고대미지 스킬, 2회 발동 시 대미지 대폭 증가

### 어시스트 모드 주의사항
- 4번 또는 5번 스킬(강화 볼트 소모)로 2번 스킬을 강화한 뒤 강화된 2번 스킬(균열 룬)로 메인 딜을 넣는 구조
- 어시스트 모드 사용 시 강화 후 1번·3번을 사용하는 잘못된 순서로 동작해 딜 효율 저하 → 수동 운용 권장

### 딜 사이클
1. `4 → 2`로 시작
2. `4 → 4 → 2` 반복
3. `3 → 1`로 스택 충전
4. 스킬 쿨타임 공백 시 궁극기 사용

### 스탯 분배
- 치명타 우선 확보 (**7,500 초과 금지**)
- 나머지: 추가타·연타 강화·강타 강화 분배
- 어비스: **브치셋** (브레이크·치명타 집중 세팅) 사용

### 보석 세공
- 주력기 태그: 2·3·4번 스킬 (원소·강타 계열)
- 우선순위: **원소 → 강타 → 연타**
- 2줄: 강타 대미지
- 3줄: 연타 대미지 추가

### 펫
- 1순위: 치명타·연타 강화
- 대체: 치명타·강타 강화

### 아티팩트
- 종결 세팅: **연타 ×3 + 추가타 확률 + 치명타 확률**
- 어비스: 연타 1개 → **분쇄**로 교체
- 힐러 있을 경우: **순수** 추가 선택 가능

### 룬워드
- 계속 이어지는 이야기 / 유리대포 / 가벼운 마음
- 피의 굶주림 (전투력 증가용)
- 쏟아지는 별 보유 시: **맹렬한 돌진**
- 미보유 시: 얼음과 불 등 대체

### 인챈트
- 프리즘으로 치명타 확보
- 나머지 스탯: 추가타·연타 강화·강타 강화 균등 분배
- 무기 인챈트: **활기**
