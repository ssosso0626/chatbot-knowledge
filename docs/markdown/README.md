
# Markdown 문서 폴더

이 폴더에는 챗봇 지식으로 사용할 **Markdown 문서**를 저장합니다.

Markdown 문서는 구조가 잘 정리되어 있어  
AI가 이해하기 가장 좋은 형태의 문서입니다.

## 사용 예시

- 서비스 설명 문서
- 기능 가이드
- 기술 문서
- 튜토리얼

## 처리 방식

업로드된 Markdown 문서는

1. 텍스트 파싱
2. 문단 분리
3. 중요 정보 추출
4. 지식베이스 저장

과정을 거쳐 챗봇 지식으로 사용됩니다.

## 파일 예시

intro.md  
terms.md  
feature_guide.md
