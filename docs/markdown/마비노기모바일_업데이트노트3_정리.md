- **쐐기**: 공격 시 무방비 상태 대상에게 방어구 파괴 부여, 10초 동안 받는 피해 10% 증가 (재사용 10초)

**엠블럼 룬:**

## 신규 시스템

### 마이홈 (하우징 시스템) [날짜: 2025-12-18]

에린 세계 내 모험가 고유의 공간을 구축하는 하우징 시스템.

**소유권 취득:**
1. 메인 퀘스트 '모험가 길드' 완료 후 던바튼 관청 에반과 대화
2. 사이드 퀘스트 '아늑한 나의 집 마이홈' 수락 후 던바튼 은행 오스틴과 대화
3. 던바튼/이멘마하에서 골드로 구매 (서버 단위로 1개 보유)

**구매 비용:**
| 종류 | 필요 골드 | 필요 데코 점수 |
|---|---|---|
| 소형 | 10,000 | 0점 |
| 중형 | 50,000 | 650점 |
| 대형 | 2,000,000 | 3,800점 |

**입장:**
- 던바튼/이멘마하 타운맵에서 '마이홈 입구' 위치 확인 후 입장
- 친구 목록/소셜 숏컷의 [마이홈 놀러가기]로 친구의 마이홈 이동

**데코 시스템:**
- 데코는 가구, 장식, 벽지, 바닥 등 마이홈 꾸미기 아이템 통칭
- 처음 획득 시 상자 형태로 지급, 개봉 후 배치 가능
- 최초 획득하는 가구는 상자 개봉 시 데코 점수 획득
- 레어 희귀도 이상 데코 상자만 거래소 거래 가능 (최초 1회)
- 획득 방법: 제작, 거래소, NPC 상점(갈빈, 플로라)

**데코 점수 해금 콘텐츠:**
| 데코 점수 | 콘텐츠 |
|---|---|
| 300점 | 제작대 2레벨 업그레이드 |
| 650점 | 중형 마이홈 구매 |
| 1,900점 | 데코 제작 부품+ 상점/물물교환 |
| 2,600점 | 재료 전송기 제작 |
| 3,000점 | 제작대 3레벨 업그레이드 |
| 3,800점 | 대형 마이홈 구매 |
| 4,800점 | 제작대 4레벨 업그레이드 |
| 5,200점 | 귀환 신호기 제작 |
| 5,500점 | 상급 데코 제작 부품 상점/물물교환 |

**특수 가구:**
- **재료 전송기**: 마이홈에 배치 시 가공 및 제작 진행 시 보관함 재료 사용 가능 (가방 → 보관함 → 공용 보관함 순)
- **귀환 신호기**: 외부에서 마이홈으로 순간이동 가능 (던전, 레이드 등 일부 지역 제외)

**마이홈 설정:**
- 이름 및 소개 변경 가능
- 입장 제한 설정 (친구/파티원/길드원)
- 퇴거 후 새 마이홈 구매 가능 (퇴거 대기 시간 5초) [날짜: 2026-02-12]

**관련 시스템:**
