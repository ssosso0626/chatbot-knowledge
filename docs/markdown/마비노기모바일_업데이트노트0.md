## 신규 콘텐츠

### 어비스 [날짜: 2025-06-19]

#### 해금 조건
- 메인 스토리 퀘스트 전체 클리어 → 모든 심층 던전 클리어 → [더 깊이, 더 아래로] 퀘스트 완료
- 이후 던바튼 관청 NPC 에반과 '심층 너머, 심연으로' 키워드로 튜토리얼 시작
- 튜토리얼 완료 시 [메뉴(≡)] – [어비스] 메뉴 해금

#### 던전 종류
- 가라앉은 유적 / 무너진 제단 / 파멸의 전당 (순서 무관 선택 가능)

#### 난이도 단계
- 솔로 → 입문 → 어려움 → 매우 어려움 → 지옥 1 → 지옥 2 → 지옥 3 → 지옥 4 → 지옥 5
- 다음 난이도 해금 조건: 이전 단계를 10분 이내(타임어택) 클리어
- 한 번 해금한 난이도는 계속 유지
- **솔로 단계**: 동행 NPC와 플레이 가능, 입문보다 낮은 난이도

#### 입장 조건
- 4인 파티로만 입장 가능 (솔로 단계 제외)
- 솔로 단계: 동행 NPC와 단독 플레이

#### 입장 횟수
- 제한 없이 입장 가능, 단 클리어 보상은 주 3회만 획득 가능

#### 보상
- 클리어 보상: 매주 월요일 오전 6시 초기화 후 재획득 가능
- 타임어택 보상: 던전별 최초 클리어 시 1회만 획득
- 주간 보상: 한 주간 최대 클리어 단계 기준으로 지급
  - 획득 가능한 [심연의 화석]을 NPC 몰리에게 아이템 교환 가능
  - 주간 보상 미수령 시 어비스 입장 불가
- 지옥 1, 2 클리어 보상에 전설 희귀도 룬 14종 포함 (무기 3종/방어구 9종/엠블럼 2종)

#### 초기화
- 매주 월요일 오전 6시 초기화

### 망령의 탑 [날짜: 2025-05-29]

#### 해금 조건
- 캐릭터 레벨 65 달성 시 자동 수락되는 '그림자를 따라서' 사이드 퀘스트 클리어

#### 입장 방법
- [메뉴(≡)] – 망령의 탑 메뉴로 입장
- 별도 재화 없이 입장 가능
- 일일 도전 가능 횟수: 5회 (성공/실패 무관 차감, 매일 오전 6시 초기화)
- 마을에서만 입장 가능, 파티 가입 상태로 입장 시 파티 자동 탈퇴
- 입장 시 궁극기 게이지 충전 상태로 시작
- 부활 아이템 사용 불가

#### 진행 방법
- 총 20층 (1~20층), 5층 단위로 보스 몬스터 등장
- 각 층마다 제한 시간 내 클리어 조건 달성 필요
- 클리어 조건 종류:
  1. 제한 시간 내 몬스터 전부 처치
  2. 망령의 초석 지켜내기 (치유 스킬로 초석 회복 가능)
  3. 제한 시간 동안 쓰러지지 않기
- 클리어 보상: 최초 1회만 지급
- 최초 입장 시 1층부터 순차 도전, 클리어한 층은 재도전 불가

#### 밸런스 조정 [날짜: 2025-05-29]
- 5-5 보스 오거의 최대 체력 50% 감소
- 초석 최대 체력 50% 증가
- 대부분 몬스터 공격력 20% 감소
- '시간 내 클리어' 스테이지 클리어 시간 30초 증가

### 인챈트 시스템 [날짜: 2025-06-19]
- 인챈트 스크롤의 효과를 장비에 영구적으로 부여하는 신규 성장 시스템
- 인챈트 스크롤은 무기/방어구/장신구/엠블럼 전용으로 구분
- 스크롤마다 기본 효과 1종 + 정해진 확률로 보너스 효과 0~2개 부여
- 인챈트 효과가 적용된 장비에 새 스크롤 사용 시:
  - 기본 효과: 교체

- 성능 주입 시 '주입 대상 장비'의 인챈트 효과가 적용됨 (재료 장비 효과 미적용)
