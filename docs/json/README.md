
# JSON 데이터 폴더

이 폴더에는 챗봇 지식에 사용할 **JSON 데이터**를 저장합니다.

JSON 파일은 구조화된 데이터를 제공할 때 사용합니다.

## 사용 예시

- 질문/답변 예시 데이터
- 용어 사전
- 설정 데이터
- 예시 문장 데이터

## 처리 방식

JSON 데이터는 다음 과정을 통해 챗봇 지식으로 변환됩니다.

1. 데이터 구조 분석
2. 텍스트 추출
3. 필터링 및 정제
4. 지식베이스 저장
